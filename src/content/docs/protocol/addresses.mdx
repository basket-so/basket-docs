## Program-derived addresses

For integrators, these are the seeds the program uses to derive its accounts. `u8` and `u64` values are little-endian bytes.

| Account | Seeds |
|---|---|
| Protocol config | `"protocol-config"` |
| Staking pool | `"staking-pool"` |
| Staking vault authority | `"staking-authority"` |
| Stake position | `"stake-position"`, pool, owner |
| Price oracle | `"price-oracle"` |
| Index (basket) | `"index"`, authority, symbol |
| Basket token mint | `"index-mint"`, index |
| Vault authority | `"vault-authority"`, index |
| Component page | `"large-basket-component-page"`, index, page index (`u8`) |
| Mint or redeem intent | `"large-basket-intent"`, index, owner, nonce (`u64`) |
| Intent lock | `"large-basket-intent-lock"`, index, owner |
| Refund escrow | `"refund-escrow"`, index |
| Rebalance intent | `"rebalance-intent"`, index, nonce (`u64`) |
| Composition change | `"composition-change"`, index |

Component vaults are the vault authority's associated token accounts for each component mint, under that token's own program.
